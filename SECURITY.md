# Security policy

Kemdara is research and educational software. It is not a production protocol, VPN, TLS replacement, key-management system, or cryptographic certification tool.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not publish working exploit details before there has been a reasonable opportunity to investigate.

Include the affected commit, operating system and architecture, reproduction steps, expected result, observed result, and whether secret material or benchmark integrity is affected.

## Scope

Security reports about Kemdara's adapters, unsafe secret handling, dependency integration, result integrity, or misleading security claims are in scope. General cryptanalysis of the standardized primitives should be reported to the relevant upstream project and standards body as well.
